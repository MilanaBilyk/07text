# СловоМетр
Создатель / владелец: **Bilyk Milana**. © 2026 Bilyk Milana. Все права защищены.

бесплатный набор инструментов для работы с текстом: подсчёт, очистка и анализ ключевых слов.

## Публикация на Cloudflare Pages
Framework preset: **None**. Build command: **оставить пустым**. Build output directory: **/** (корень).
Это обычный статический сайт, сборка не нужна.

## Что заполнить перед запуском
1. `contacts.html`, `privacy.html`, `terms.html`: все жёлтые поля [ЗАПОЛНИТЕ].
2. `robots.txt` и `sitemap.xml`: замените `ВАШ-ПРОЕКТ.pages.dev` на реальный адрес после публикации.
3. Юридические тексты — шаблоны. Проверьте их перед коммерческим запуском.

## Монетизация (пока не подключена)
- Реклама: на главной есть пустой блок `<div class="slot">`. Вставьте туда код рекламной сети (после одобрения сети) и обновите политику конфиденциальности.
- Платные функции: потребуется платёжный сервис и серверная часть (Cloudflare Workers) для проверки оплаты.

## Ограничения
Нет серверной части, бесплатных лимитов хостинга хватает с запасом. Проверка орфографии не реализована (нужны словари); это можно добавить позже.
